# ScrollSplit 설명서

트랙패드는 자연스러운 스크롤, 마우스는 일반 스크롤로 **동시에** 쓰게 해 주는 맥 메뉴 막대 앱입니다. 무료·오픈소스이고, 네트워크를 전혀 쓰지 않습니다.

## 0. 이런 분께 필요합니다

macOS의 "자연스러운 스크롤"은 트랙패드 설정과 마우스 설정에 따로 있는 것처럼 보이지만 실제로는 스위치 하나입니다. 하나를 바꾸면 다른 쪽도 바뀝니다. 그래서 맥북 트랙패드와 휠 마우스를 같이 쓰면 둘 중 하나는 항상 반대로 움직이고, 마우스를 꽂을 때마다 설정을 껐다 켜야 합니다.

## 1. 내려받기

[Releases](https://github.com/subbak2/ScrollSplit/releases)에서 `ScrollSplit.zip`을 받아 압축을 풀고, `ScrollSplit.app`을 **응용 프로그램** 폴더로 옮깁니다. macOS 13 이상이 필요합니다.

## 2. 처음 실행하기 (한 번만)

1. `ScrollSplit.app`을 더블클릭합니다. 공증(유료 Apple 개발자 계정 필요)을 받지 않은 앱이라 처음에는 macOS가 막습니다. **완료**를 누릅니다.
2. **시스템 설정 › 개인정보 보호 및 보안**에서 아래로 내려 *"ScrollSplit"이(가) 차단되었습니다* 옆의 **그래도 열기**를 누르고 암호나 Touch ID로 확인합니다.
3. 손쉬운 사용 권한을 묻는 창이 뜹니다. **시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용**에서 ScrollSplit을 켭니다. 2초 안에 동작을 시작하고, 앱을 다시 켤 필요는 없습니다.

1~2단계는 터미널 명령 한 줄로 대신할 수 있습니다.

```
xattr -dr com.apple.quarantine /Applications/ScrollSplit.app
```

## 3. 쓰는 법

메뉴 막대의 위아래 화살표 아이콘을 누릅니다.

- **자연스러운 스크롤 › 트랙패드 / 마우스**: 자연스럽게(손가락 방향대로 화면이 움직이게) 쓸 기기에 체크합니다. 기본값은 트랙패드 켬, 마우스 끔입니다.
- **마지막 스크롤 / 시스템 설정**: 앱이 알아본 기기와 시스템 설정 값입니다. 방향이 이상하면 여기부터 봅니다.
- **일시 정지**: 앱을 완전히 끕니다. 모든 기기가 시스템 설정을 따릅니다.
- **로그인 시 실행**: 맥을 켤 때 자동으로 실행합니다.

시스템 설정의 자연스러운 스크롤을 켜 두든 꺼 두든 상관없습니다. 메뉴에서 체크한 대로 움직입니다.

## 4. 개인정보와 보안

- **네트워크를 쓰지 않습니다.** 네트워크 코드가 없고, `scripts/check-no-network.sh`로 실행 파일에 네트워크 기능이 없는지 확인할 수 있습니다. 실행 중에도 네트워크 연결(소켓)이 하나도 없습니다. 메뉴의 "ScrollSplit 정보…"는 브라우저로 이 저장소를 여는 것뿐입니다.
- **손쉬운 사용 권한 하나만 씁니다.** 다른 앱으로 가는 스크롤을 바꾸려면 macOS가 이 권한을 요구합니다. 이 앱은 **스크롤 이벤트만** 받습니다. 키보드 입력, 클릭, 커서 이동은 앱에 전달되지 않습니다. 입력 모니터링 같은 다른 권한은 요청하지 않습니다.
- **저장하는 것은 설정 세 개**(트랙패드, 마우스, 일시 정지)뿐입니다. 로그 파일이나 통계는 없습니다.
- **Hardened Runtime**을 켜서, 다른 프로그램이 이 앱에 코드를 끼워 넣어 권한을 빌려 쓰는 것을 막습니다.
- 내려받은 실행 파일이 꺼림칙하면 소스(약 300줄)를 직접 빌드해서 쓰면 됩니다(8장).

## 5. 안전장치와 복구 방법 (벽돌이 되지 않나요?)

이 앱은 지나가는 스크롤 이벤트의 숫자 부호만 바꿉니다. 시스템 설정을 바꾸거나 파일을 고치지 않으므로, **앱을 끄면 언제나 원래대로 돌아옵니다.**

- **스크롤이 멈추거나 이상하면**: 메뉴에서 종료하거나 터미널에서 `killall ScrollSplit`. 프로세스가 끝나는 순간 macOS가 스크롤 가로채기를 없앱니다.
- **앱 없이 시작하기**: **Shift**를 누른 채 실행하면 일시 정지 상태로 시작합니다.
- **앱이 멈춰도**: macOS가 약 1초 뒤 가로채기를 꺼서 스크롤은 그대로 됩니다. 앱이 회복되면, 그리고 잠자기에서 깨어날 때 다시 켭니다.
- **실행 중에 손쉬운 사용 권한을 빼면**: 앱이 바로 가로채기를 없애고 권한을 다시 기다립니다.
- **macOS 업데이트 뒤**: 공개 API(Quartz Event Services)와 시스템 설정 값 `com.apple.swipescrolldirection`만 씁니다. 설정 변경 알림 이름이 바뀌어도 스크롤 중 5초마다 다시 읽습니다. 업데이트로 트랙패드 신호 방식이 바뀌면 최악의 경우 기기를 잘못 알아봐 방향이 반대가 되는 정도이고, **일시 정지**나 종료로 바로 원래대로 돌아옵니다. 업데이트 뒤 동작하지 않으면 손쉬운 사용 목록에서 ScrollSplit을 **−**로 빼고 다시 켭니다.
- **새 버전으로 바꾼 뒤**: 서명이 바뀌어 macOS가 다른 앱으로 볼 수 있습니다. 손쉬운 사용 목록에서 빼고(−) 다시 켭니다.

## 6. CPU·GPU·메모리 사용량

MacBook Pro M1 Max, macOS 27에서 `top`·`ps`(5초 간격)와 `ioreg`(GPU)로 잰 값입니다.

| 상태 | CPU | GPU | 메모리 |
|---|---|---|---|
| 가만히 있을 때 | 0.0% | 사용 없음 | 약 22MB |
| 1분 동안 트랙패드·마우스 번갈아 스크롤 | 평균 약 1%, 빠르게 스크롤하는 순간 한 코어의 최대 5% 정도 | 사용 없음 | 변화 없음 |

켜 둬도 배터리에 느껴질 만한 영향은 없습니다.

## 7. 알려진 한계

- **Magic Mouse**는 트랙패드처럼 신호를 보내서 **트랙패드** 설정을 따릅니다.
- **드라이버에서 부드러운 스크롤을 켠 마우스**(예: Logi Options+의 "부드러운 스크롤")는 트랙패드로 분류될 수 있습니다. 드라이버의 부드러운 스크롤을 끄거나 **일시 정지**를 씁니다.
- **스크롤 앱을 여러 개 같이 쓰면**(Scroll Reverser, Mos, LinearMouse, Logi Options+ 스크롤 기능, Karabiner-Elements 등) 같은 스크롤을 두 번 뒤집을 수 있습니다. 하나만 쓰세요.
- **원격 데스크톱·화면 공유·유니버설 컨트롤**로 들어오는 스크롤은 다르게 분류될 수 있습니다. 방향이 이상하면 메뉴의 *마지막 스크롤*을 확인하세요.
- **iPhone 미러링**과 일부 게임은 이 방식의 영향을 받지 않을 수 있습니다.

## 8. 문제가 생겼을 때 / 직접 빌드

기기별 진단 로그 보기:

```
defaults write io.github.subbak2.ScrollSplit debug -bool true   # 앱을 껐다 켭니다
/usr/bin/log stream --level debug --predicate 'subsystem == "io.github.subbak2.ScrollSplit"'
defaults delete io.github.subbak2.ScrollSplit debug             # 다시 끄기
```

설정 초기화: `defaults delete io.github.subbak2.ScrollSplit` · 손쉬운 사용 항목 초기화: `tccutil reset Accessibility io.github.subbak2.ScrollSplit`

직접 빌드(Xcode 명령줄 도구 필요): `scripts/build-app.sh` → `build/ScrollSplit.app`. `scripts/check-no-network.sh`로 네트워크 없음 확인, `swift test`로 기기 구분·방향 뒤집기 테스트.

## 9. 끄기와 삭제

메뉴 › 종료. 삭제는 응용 프로그램 폴더에서 `ScrollSplit.app`을 휴지통에 버리고, 손쉬운 사용 목록에서 **−**로 뺀 뒤 `defaults delete io.github.subbak2.ScrollSplit`.
